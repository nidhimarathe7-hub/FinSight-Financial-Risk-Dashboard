# FinSight — Financial Risk & Investment Dashboard

FinSight is a financial analytics project that studies historical
stock-price movements and investment risk using real market data.

## Features
- Historical closing-price charts
- Return comparisons
- Annualized volatility
- Maximum drawdown analysis
- Interactive asset and date filters
- Downloadable filtered data

## Technology
- Python
- PySpark for data processing
- Pandas
- Plotly
- Streamlit

## Run locally
1. Install the dependencies:
   `pip install -r requirements.txt`
2. Place both CSV data files beside `app.py`.
3. Run:
   `streamlit run app.py`

## Data
The dashboard uses historical market data downloaded for educational
and research purposes. Review the data provider's terms before
redistributing the dataset.
